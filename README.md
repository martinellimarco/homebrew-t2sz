# Homebrew Tap for t2sz

[t2sz](https://github.com/martinellimarco/t2sz) compresses a file into a seekable zstd with per-file seeking for tar archives.

## Install

```bash
brew tap martinellimarco/t2sz
brew install t2sz
```

## Update

```bash
brew update
brew upgrade t2sz
```

## Uninstall

```bash
brew uninstall t2sz
brew untap martinellimarco/t2sz
```
